# Еженедельная отчетность по советникам ЛНР

Веб-приложение Flask для координаторов муниципалитетов и регионального администратора. Один отчет муниципалитета на отчетную дату, по всем его образовательным организациям; в каждой организации учитываются штатные единицы, занятые ставки, вакансии, советники (в том числе совместители и временно отсутствующие) и начисленные/фактические выплаты по каждому человеку. Фактически работающие определяются по статусу «Работает». Администратор видит сводку, не сдавших отчет, журнал исправлений и скачивает Excel с тремя листами: муниципалитеты, организации, советники и выплаты.

## Запуск (PowerShell)

```powershell
python -m pip install -r requirements.txt
python -m flask --app app init-db
python -m flask --app app create-admin
python -m flask --app app run
```

Откройте `http://127.0.0.1:5000/`. В рабочую базу уже загружены 28 муниципалитетов и 900 организаций из `C:\Users\Админ\Documents\советники\Актуальный_справочник_10_09_2026.xlsx`. Для повторной загрузки актуальной версии выполните:

```powershell
python -m flask --app app import-directory --path "C:\путь\к\Актуальный_справочник.xlsx"
```

Веб-импорт понимает исходные столбцы **АТЕ**, **Название образовательной организации**, **Тип** и статус осуществления образовательного процесса. Также поддерживается сокращенный шаблон **Муниципалитет | Организация | Тип**. Повторный импорт добавляет новые организации и обновляет их тип/статус, но не удаляет отсутствующие в новой версии записи. Названия можно исправлять вручную. После импорта создайте учетные записи координаторов. Повторный `init-db` дополняет существующую базу новыми таблицами/полями; перед обновлением сделайте резервную копию `reports.sqlite3`. Старые дневные отчеты остаются в базе, но не содержат новых недельных показателей и не преобразуются автоматически.

По умолчанию отчетная дата — последний прошедший четверг, срок сдачи — тот же день. Администратор может назначить иную отчетную дату и срок сдачи на панели сводки. Если дата сдачи прошла, в кабинетах показывается предупреждение; автоматическая отправка писем/SMS не настроена. Для работы с прошлым отчетом координатор выбирает дату в своем кабинете. Повторное сохранение хранит предыдущую версию в журнале базы. Показатель задолженности в выгрузке = начислено минус выплачено за введенный месяц, это не бухгалтерская задолженность с учетом прошлых периодов.

Финансовый блок основан на постановлении Правительства ЛНР от 03.12.2024 № 253/24: отдельно учитываются ежемесячное вознаграждение, страховые отчисления, выплата среднего заработка и фактическая выплата советнику. При полностью отработанном месяце система требует вознаграждение ровно 5 000 руб. независимо от ставки. Для одного ФИО и месяца можно отметить только одну организацию выплаты; совпадение в отчете другого муниципалитета блокируется с указанием найденной организации. Это контроль отчетности по ФИО, а не надежная идентификация человека: для исключения однофамильцев в будущем потребуется устойчивый идентификатор. Размер страховых отчислений система не рассчитывает, поскольку конкретный тариф постановлением № 253/24 не установлен. Система не заменяет бухгалтерский расчет.

Для тестов: `python -m unittest discover -s tests -v`.

## Публикация

Встроенный `flask run` не предназначен для публичного доступа. Нужны HTTPS, регулярные резервные копии базы, ограничение попыток входа на прокси и переменные окружения `SECRET_KEY` (случайное длинное значение), `HTTPS_ONLY=1`, при необходимости `REPORT_DB` (путь к базе). Локальный `.secret-key` и база не должны публиковаться. В отчетах есть ФИО советников и сведения о выплатах: доступ к серверу, резервным копиям и срок хранения данных согласуйте с ответственным за персональные данные. `index.html` — старый автономный прототип, не связан с этим сайтом.
